Bạn đang mở trang này bằng công cụ file tĩnh (Live Server / Live Preview) hoặc trực tiếp từ file — nên nút “Tạo PDF” sẽ báo lỗi HTTP 405. Cần chạy server Flask và mở đúng địa chỉ: 

cd "d:\MCP\Claude Code\anh-giay-to-xe"
python app.py

Sau đó mở http://127.0.0.1:5000 trong trình duyệt.
